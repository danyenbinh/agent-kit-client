# Pricing summary (customer)

Full vendor sheet (indicative Y1): see cloud `gtm/PRICING.md` when under NDA.

## What you buy

| SKU | You get |
|-----|---------|
| **Core** (free / starter) | Tip + **basic Unity MCP** (bridge / compile / verify) + **PKE** + **ISR** usage tools |
| **Unity Pro** | + **VFX** authoring |
| **Unity Studio** | + Shader Graph, Figma HUD, **Builder**, Review cloud |

**Not in Core:** VFX, Builder, Shader Graph (Pro / Studio).

**Hosts are free** with Core. Invoice is by **org seats + domain SKU**, not by IDE.

## Year 1 billing

**Core free:** offline Init (extension / `init-agent-kit.ps1` / `agent_kit_init`) — no portal.  
**Pro/Studio:** portal license key → Apply / `sync-entitled.ps1`. Stripe on vendor portal.
